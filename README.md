# Deepsom AI website

## Version 2 UI/UX and branding enhancement

Version 2 integrates the official supplied Deepsom logo in navigation and footer, favicon metadata, Open Graph and Twitter card metadata. The visual system has been elevated with Space Grotesk display typography, Inter body copy, a brand-aligned navy, blue, cyan and magenta colour system, layered gradient surfaces, premium cards, and a refined responsive navigation.

The homepage now includes a branded neural-network hero, subtle animated visual elements, future partner placeholders, animated/revealing cards using Framer Motion, and clearly labelled placeholder testimonials. All existing routes and SEO routes remain in place.

A responsive Next.js 15 website for the Deepsom Institute of Artificial Intelligence and Emerging Technology. Editable content is kept in `content/site-content.ts`; shared UI lives in `components/`; `lib/site.ts` contains organisation configuration.

## Run locally

1. Install Node.js 20.9 or newer.
2. Run `npm install`.
3. Copy the institute URL, email and address into `lib/site.ts`.
4. Run `npm run dev` and visit `http://localhost:3000`.

## Production build

Run `npm run build`, then `npm run start`. The project uses Next.js App Router with typed routes, metadata, structured data, `sitemap.xml` and `robots.txt` generated by the application.

## Hostinger deployment

For Hostinger Node.js hosting, create a Node.js application with Node 20+, upload the source (excluding `.next` and `node_modules`), run `npm install` and `npm run build`, then set the startup command to `npm run start`. Configure the domain in `lib/site.ts` before building and set the application port to the `PORT` supplied by Hostinger. A VPS can alternatively run this behind Nginx with a process manager such as PM2.

## Content and CMS readiness

`content/site-content.ts` is deliberately data-only so it can later be replaced by a headless CMS adapter. The page components remain presentational. New content types (events, news, team and partners) can follow the same pattern.
